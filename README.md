# Business starter kit — Blank Studio (working concept)

This kit contains a bilingual concept website and launch materials for a small creative technology studio serving businesses across Puerto Rico.

## Folder structure

- `site/index.html` — bilingual website (Spanish / English)
- `site/gracias.html` — contact form thank-you page
- `brand-guide.md` — positioning, voice, visual identity, and launch checks
- `sales-playbook.md` — offer, sales process, delivery, and launch plan

## Preview locally

Open `site/index.html` in a browser. No build tools or package installation are required.

## Deploy to Netlify

1. Create a Netlify account.
2. Drag the entire `site` folder into Netlify Drop, or connect this project to a Git repository and set `site` as the publish directory.
3. In the Netlify dashboard, open Forms and enable automatic form detection. If you enable it after the first deploy, redeploy the site so Netlify parses and registers the form.
4. Confirm that `project-inquiry` appears under Forms, then add an email notification under Forms → Submission notifications. Submit a test inquiry and verify that the notification arrives.
5. Test `gracias.html`, the Spanish/English switch, mobile navigation, and every call-to-action.

The contact form uses Netlify Forms (`data-netlify="true"`). It will not submit correctly on ordinary local file preview or on hosts that do not support Netlify Forms. If hosting elsewhere, connect a form service or a backend before publishing.

## Important before using publicly

- **The name is provisional.** 
- Prices are initial proposals, not a market study or a guarantee of profitability. Update them to match actual delivery time, costs, and customer response.
- The portfolio cards are fictional concept demonstrations and are labelled as such. Do not represent them as client work.
- Review your ability to fulfil each advertised service. Scope unfamiliar work carefully or use qualified collaborators.
- Confirm applicable business registration, tax, municipal, and permit obligations in Puerto Rico with the relevant agencies and a local professional.
